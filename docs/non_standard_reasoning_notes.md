# Non-standard reasoning notes

These notes connect the project back to broader ideas in information theory and topology.

- A system can be studied through its deltas rather than through its canonical identities.
- The event horizon matters because it bounds what can validly transform.
- A witness is not a duplicate; it is an independent lens.
- Standing waves are a sign that an object is not just random noise but a recurring structural pattern.
- The void-like reference is not mere emptiness; it is the place where identity becomes interpretable.

This repository should be read as a conceptual and computational experiment, not as a final protocol specification.
